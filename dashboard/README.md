# Proxima Command Center

The React dashboard for Agata Proxima's management Control Plane.

## Scope

The dashboard presents organization-scoped platform resources, node enrollment, deployments, verification evidence, audit information, billing, identity settings, and operational status through the Control Plane API.

## Development

Follow the repository root [README](../README.md) and [usage guide](../docs/usage.md) for prerequisites, local startup, and verification commands.

## Status

Verify dashboard rendering and API integration against the running Control Plane. Displayed values should be treated as live evidence only when they are returned by the API and the relevant environment checks pass.
