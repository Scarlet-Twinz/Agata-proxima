# Private Beta Foundation

Phase 40 is the boundary between an internal platform and an external customer program.

## Customer onboarding

1. Create organization.
2. Assign owner/admin/operator/viewer membership.
3. Create project/environment.
4. Create tenants.
5. Define policy version.
6. Register Proxima node.
7. Enroll node using one-time secret.
8. Attach customer application.
9. Run verification suite.
10. Review audit events.
11. Execute failure drill.
12. Record support contact and escalation path.

## Beta acceptance evidence

Every beta customer should have:

- deployment identifier
- Proxima version
- tenant inventory
- active policy version
- node identity
- verification report
- rollback procedure
- backup/restore status
- support route
- incident escalation path

The platform must never claim a beta customer is protected merely because the dashboard is green. The evidence bundle is the acceptance artifact.
