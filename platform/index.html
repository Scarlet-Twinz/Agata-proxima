Questions we expect

Security should survive the questions.

What happens if Proxima Cloud is unavailable?

An already-running engine keeps enforcing its last accepted local policy. The control plane is not a prerequisite for each database query.

Does Proxima replace PostgreSQL RLS?

No. Proxima is a boundary and routing layer. PostgreSQL roles and RLS remain valuable defense in depth and are independently verified.

Can Proxima manage multiple environments?

The control-plane model separates organizations, projects and environments so production and staging can be operated independently.

Is this only for one database?

The first production target is PostgreSQL. The architecture is deliberately centered on explicit enforcement contracts so other data planes can be evaluated later.
