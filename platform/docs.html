Architecture

The control plane manages. The data plane enforces.

Proxima uses a logical separation between management and enforcement. The control plane distributes intent; the engine owns the live PostgreSQL boundary.

DATA PLANE

Proxima Engine

Tenant context is established once per connection. TLS and PostgreSQL session lifecycle are enforced locally.

MANAGEMENT PLANE

Proxima Control Plane

Identity, organizations, tenants, policies, nodes, deployment state and audit are managed through an authenticated API.

VERIFICATION

Proxima Verify

Negative-path tests attack malformed protocol input, identity confusion, cross-tenant operations, transactions and RLS.

Runtime contract

Cloud failure must not become an authorization bypass.

An enrolled engine receives signed policy/configuration. It validates and applies the bundle locally. Once accepted, the enforcement path does not need the cloud to decide whether a database session belongs to a tenant. If the control channel disappears, the engine continues with its last valid policy and records the control-plane degradation for operators.
