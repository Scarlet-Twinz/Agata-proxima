THE PLATFORM

One system. Three layers.

Proxima separates enforcement, verification and fleet operations so each responsibility stays explicit.

01

Proxima Engine

The Rust data plane. It owns the runtime security boundary: tenant identity, session handling, upstream routing, TLS and database access.

02

Proxima Verify

The adversarial verification layer. It tests identity attacks, cross-tenant database operations, RLS and failure behavior.

03

Proxima Cloud

The non-authoritative control plane. It manages organizations, policies, fleet state, deployments, audit, entitlements and enterprise identity.

THE CONTRACT

Management can fail without granting access.

That is not a marketing statement. It is an architectural rule: an Engine already enforcing a tenant boundary does not interpret control-plane unavailability as authorization to bypass that boundary.
