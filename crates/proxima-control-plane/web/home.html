QUESTIONS

Frequently asked.

Does Proxima require the cloud to enforce tenant isolation?

No. The architecture deliberately keeps the Engine authoritative for enforcement. The control plane can distribute policy and manage fleet state, but it is not a runtime security bypass.

What does Proxima manage?

Organizations, tenants, policies, Proxima nodes, deployment state, verification evidence, security audit events and operational support requests.

Is this another application-level tenant ID helper?

No. The project is designed around an infrastructure boundary: tenant context is established before the normal PostgreSQL query stream and remains bound to the session.

Can it support different isolation postures?

The control plane models isolation mode as an explicit tenant property, allowing future shared, bridged and dedicated deployment strategies without changing the core identity contract.

What happens when the control plane is unavailable?

Existing Proxima Engine nodes continue their local enforcement path. Availability of management services is not treated as permission to weaken the data-plane boundary.
